# Code of Conduct

## Our pledge

We want Lyra to be a welcoming project for everyone, regardless of experience
level, background, identity, or preferred terminal. Contributors and
maintainers pledge to make participation harassment-free and constructive.

## Expected behaviour

- Be respectful and assume good intent.
- Give technical feedback about code and behaviour, not about people.
- Accept that maintainers may decline changes that do not fit the project's
  scope, architecture, or maintenance budget.
- Respect the plugin contract and the security rules in
  [SECURITY.md](SECURITY.md); never submit malicious or obfuscated code.

## Unacceptable behaviour

- Harassment, insults, personal or political attacks, and discriminatory
  language.
- Publishing someone's private information without permission.
- Deliberately disruptive behaviour in issues, pull requests, or discussions.
- Submitting code intended to exfiltrate data, execute hidden payloads, or
  bypass the plugin review process.

## Scope

This policy applies in all project spaces: issues, pull requests, discussions,
commit messages, and any space where someone represents the project.

## Enforcement

Report incidents privately to the maintainer
[@vincentlalo-long](https://github.com/vincentlalo-long) through GitHub. Reports
are reviewed confidentially. Maintainers may edit or remove contributions, and
may temporarily or permanently ban contributors for behaviour they consider
inappropriate, threatening, or harmful.
